01 / THE FAILURE

The metric goes up. The task goes missing.

Measured, not a mock chart

Repetition and positive padding compete with useful content inside an 80-word budget. The optimizer receives only the naïve proxy; it never receives a “be unhelpful” instruction or the held-out rubric score.

The fixed style alert first fired at checkpoint 80. Training continued so the full failure remains visible. Bands describe variation across 5 seeds on one fixed 12-case test set; they are not patient-population uncertainty.

02 / THE DESIGN

One pipeline. Three information boundaries.

01 · TASK48 fictional messages

24 training · 12 calibration · 12 test. Scenario groups do not cross splits.

02 · GENERATEA small stochastic policy

Choose empathy count, positive padding, and specific vs. generic content.

03 · OPTIMIZEA deliberately bad proxy

Phrase counts + positive sentiment tokens + a length bonus. Only this score updates the policy.

04 · CHECKAn independent style gate

Length, empathy density, and repeated sentences. Thresholds use calibration references only.

Evaluation-only lane: a separate lexical rubric checks concern coverage, a relevant next step, concision, and narrow assurance rules. It cannot update the policy or choose a served response.

“Independent” means separated inputs and code paths, not statistically independent errors. The rubric and monitor share some style cues, and templates cover every scenario.

04 / THE INTERVENTION

Gate the candidate, not the evaluation score.

In a separate test, both selectors see the same nested pools from the frozen initial generator. One picks the highest proxy score. The other rejects flagged candidates first, then maximizes the same proxy. If nothing passes, it abstains.

Known blind spots

Short positive-word lists can evade this monitor. Legitimate long replies can be flagged. A concise but wrong answer may look completely normal. The rubric itself can be gamed by lexical overlap.

The engineering lesson: keep optimization, evaluation, and monitoring separate; report coverage with quality; and retain failures as regression cases instead of declaring alignment solved.
What the experiment demonstrates—and what it does not

The finite action space deliberately includes repetition and padding. A real policy-gradient update shifts probability toward those actions because of their measured reward. This demonstrates proxy exploitation in a designed environment, not a novel emergent exploit in a neural language model.

Held-out evaluation is still imperfect

The lexical rubric is hand-authored, shares vocabulary with the task templates, and misses semantic errors. Template content exists for every scenario, including test scenarios. A blinded review CSV is included for independent checking; its rating cells are blank because no human review has been performed.

Real-model extension

The repo includes an optional Ollama candidate collector and the same paired best-of-N experiment. Its HTTP behavior is unit-tested with mocks, but no live model run is included here. Real-model outputs are saved unchanged; a hack is not guaranteed. The default lexical evaluator and template-calibrated thresholds must be validated before interpreting model results.
